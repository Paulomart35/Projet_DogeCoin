# Projet_DogeCoin

Ce projet récupère en continu le prix de Dogecoin depuis l'API CoinGecko (via un script Bash exécuté toutes les 5 minutes) et affiche ces données sous forme de graphiques interactifs et d'indicateurs techniques sur un dashboard web développé en Python avec Dash. Un rapport quotidien est également généré et affiché pour suivre l'évolution journalière.

## Principales fonctionnalités
- Scraping automatique : Récupération des données toutes les 5 minutes.

- Dashboard interactif : Visualisation en temps réel du prix, moyennes mobiles, bandes de Bollinger, graphique candlestick, histogramme des rendements, etc.

- Rapport quotidien : Génération et affichage d’un rapport quotidien (prix d'ouverture, de clôture, volatilité, etc.).
